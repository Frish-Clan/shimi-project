# חיפוש והורדה סלקטיבית מארכיון ישראבלוג (2003–2005)

הסקריפט `israblog_search.py` עובד מול ארכיון ישראבלוג ש-Arquivo.pt סרקו ב-2019. הארכיון מאוחסן ב-archive.org כפריטים בשם
`portuguese-web-archive-EAWP19-2019-00NN`. כל פריט כולל קובצי WARC וקובץ אינדקס `.cdx.gz`.

## איך זה עובד

קובץ ה-CDX מכיל **רק כתובות URL**, בלי הטקסט של הבלוגים. לכן התהליך מתחלק לשלושה שלבים:

1. **index**: קורא את קובץ ה-`.cdx.gz` בזרימה, בלי לשמור אותו כולו על הדיסק. הוא שומר רק דפי HTML של ישראבלוג ומחלץ מה-URL את
   מספר הבלוג, השנה והחודש (`blogread.asp?blog=123&year=2004&month=5`). דפים עם שנה מחוץ לטווח 2003–2005 מסוננים כבר כאן.
2. **search**: לכל בלוג נשלפים רק הדפים שלו מהשנים הרלוונטיות, ישירות מתוך קובץ ה-WARC בבקשות HTTP Range. כל בקשה מורידה
   כמה KB בלבד ולא את כל קובץ ה-WARC, ששוקל כמה ג'יגה. הטקסט מפוענח (windows-1255), והסקריפט מחפש בו את המונחים.
   כשבלוג נמצא מתאים, החיפוש בו נעצר.
3. **download**: לבלוגים שנמצאו מתאימים, הסקריפט מוריד את כל הדפים מ-2003–2005 ושומר:
   - קובץ HTML קריא ב-UTF-8 לכל דף, וגם `index.html` עם רשימת הדפים
   - קובץ `blog_<id>.warc.gz` קטן, שאפשר לפתוח ב-[ReplayWeb.page](https://replayweb.page) ולגלוש בבלוג כמו באתר המקורי

## שימוש

נדרש Python 3.9 ומעלה. לא צריך להתקין ספריות.

```bash
# 1. בניית אינדקס מקומי (אפשר לחזור עם --append לפריטים נוספים: 0001, 0002, ...)
python israblog_search.py index \
  --cdx https://archive.org/download/portuguese-web-archive-EAWP19-2019-0028/portuguese-web-archive-EAWP19-2019-0028.cdx.gz \
  --out index.tsv

# 2. חיפוש (any = אחד המונחים מספיק, all = כל המונחים חייבים להופיע בבלוג)
python israblog_search.py search --index index.tsv --term "חיפה" --term "טכניון" --mode all --out matches.tsv

# 3. הורדת הבלוגים שנמצאו
python israblog_search.py download --index index.tsv --matches matches.tsv --out-dir blogs

# או הורדה ישירה של בלוג שמספרו ידוע
python israblog_search.py download --index index.tsv --blog 12345 --out-dir blogs
```

אפשרויות שימושיות:

- `--years 2003-2005`: טווח השנים (זו ברירת המחדל)
- `--workers 6`: מספר בקשות במקביל. כדאי לא להגזים, כדי לא להעמיס על archive.org
- `--max-pages 20`: מגביל את מספר הדפים שנבדקים בכל בלוג, לחיפוש ראשוני מהיר
- `--regex`: מאפשר לכתוב את המונחים כביטויים רגולריים
- `--warc-dir DIR`: קורא קובצי WARC שכבר הורדו למחשב, במקום לפנות לרשת
- אם החיפוש נעצר באמצע, מריצים את אותה פקודה שוב והיא ממשיכה מאותה נקודה (`matches.tsv.searched`)

## מגבלות שחשוב לדעת

- הקישור הוא **חלק אחד** (0028) מתוך סדרה של פריטים. כדי לכסות את כל ישראבלוג צריך להריץ `index --append` על כל
  קובצי ה-CDX של הסדרה.
- **תאריך הסריקה ב-CDX הוא 2019**, ולא תאריך הפוסט. לכן השנה נלקחת מפרמטרי ה-URL (`year=`, `month=`). בפוסט בודד
  (`blogcode=`) אין שנה ב-URL, והשנה מזוהה לפי תאריכים בתוך הטקסט.
- החיפוש מתבצע על הטקסט שנמצא בתוך הארכיון. אם דף לא נסרק, אי אפשר למצוא אותו.
- דרך מהירה לבדוק לפני כן: ל-Arquivo.pt יש חיפוש טקסט מלא, למשל
  `https://arquivo.pt/textsearch?q=<מונח>&siteSearch=israblog.nana10.co.il`.
  כדאי לבדוק שם אם המונח נמצא, ואם כן לקבל את מספר הבלוג ולהוריד ישירות עם `--blog`.
